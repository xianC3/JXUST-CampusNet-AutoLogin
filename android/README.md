# Android 通用版

原生 Android 自动登录应用，不依赖 Termux。

## 环境

- Android Studio
- Android SDK 35
- JDK 17
- minSdk 26
- targetSdk 35
- 当前版本：2.5.1，versionCode 18

## 编译

用 Android Studio 打开本目录，等待 Gradle 同步完成，然后运行 `app` 模块。

也可以在 Android SDK 与 JDK 已配置好的环境中执行：

```powershell
.\gradlew.bat assembleDebug
```

Debug APK 输出到 `app/build/outputs/apk/debug/`。

仓库不包含正式签名密钥，release 包默认不签名。发布前请自行创建并妥善保管签名配置，不要把私钥提交到 GitHub。

## 首次配置

1. 安装并打开应用。
2. 允许定位、附近设备和通知权限。
3. 填写自己的校园网账号，不要手动填写 `@` 后缀。
4. 选择学校要求的运营商。
5. 填写密码并点击“保存账号并登录”。
6. 连接校园 Wi-Fi，点击“添加当前 WI-FI 为校园网”。

校园内存在多个 Wi-Fi 名称时，分别连接后逐个添加。点击“管理校园网名单（可删除）”可以删除不再使用的网络。

## 网络状态兼容

- 正确识别门户的“登陆数已上限 / Limit Users Err”文本。
- 门户返回“系统忙”等临时错误时自动重试。
- 门户状态接口异常但校园 Wi-Fi 外网可用时，不误报为未连接。
- 外网确认可用后向 Android 上报网络连通性，尝试同步系统验证状态。
- 找不到本机 MAC（读取不到或在线列表中不存在）时，通过自助服务仅注销登录时间最早的会话。

## 后台运行

- 小米 HyperOS：开启自启动，将省电策略设为“无限制”，允许后台活动。
- 荣耀 MagicOS：在“应用启动管理”中关闭自动管理，允许自启动、关联启动和后台活动。
- 其他品牌：在应用信息或手机管家中允许自启动和后台运行。

## 隐私

账号和密码保存在应用私有存储中。源码没有预置任何账号、密码、受信 MAC 或个人校园 Wi-Fi 名称。
