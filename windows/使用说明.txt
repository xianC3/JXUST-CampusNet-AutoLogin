江西理工大学校园网自动登录（Windows 通用版）

一、安装

1. 运行构建生成的 CampusNetManager-Setup.exe。
2. 按向导完成安装；安装过程需要一次管理员授权。
3. 从开始菜单打开“江西理工大学校园网自动登录”。

程序为自包含版本，不需要额外安装 .NET 运行时。

二、账号设置

1. 点击“账号设置”。
2. 账号栏只填写自己的学号或校园账号，不要手动添加 @ 后缀。
3. 选择接入运营商：
   校园网：不加后缀
   联通：@unicomyt
   移动：@cmccyt
   电信：@telecomyt
4. 填写密码并保存。

账号、密码或运营商选错时，校园门户会拒绝登录。重新打开“账号设置”修改即可，不需要重装。

三、校园网名单

- “添加当前 Wi-Fi”将当前校园网络加入名单。
- “管理名单”可以查看和删除校园网名称。
- 家庭网络、手机热点及其他非名单 Wi-Fi 会直接跳过。

自动切换校园网默认关闭。勾选“仅当当前网络不可上网时，允许自动
切换到可见校园网”后，程序也必须先确认当前网络无法上网、附近存在
名单中的校园网，才会切换。当前热点可以正常上网时不会被切走。

网络变化连续触发时会在 3 秒内去重。日志会区分 DNS 失败、连接拒绝、
TCP 超时、网络不可达、TLS、HTTP 状态和响应解析错误。

四、设备数达到上限

通用版不保存固定用户 MAC。设备数达到上限后，程序会登录自助服务并读取在线会话列表：

- 找到本机 MAC 时，注销最旧的一条会话，尽量保留另一台设备在线。
- 找不到本机 MAC（读取不到，或列表中没有）时，注销已注册会话中登录时间最早的一条。
- 列表中有两条会话时只注销一条，不会把其他设备全部下线。

账号密码不正确、验证码持续失败、在线列表为空或接口格式异常时，程序会停止注销并报告原因。

五、自动运行

- 勾选“登录 Windows 后自动在后台运行”。
- 程序使用当前用户计划任务，在登录后延迟约 5 秒启动。
- 网络变化和定时任务会重新检查。
- 关闭主窗口后程序留在系统托盘。

六、适用范围

当前主要在江西理工大学南昌校区网络环境测试。赣州校区尚未做具体测试；如果门户、Wi-Fi 名称、运营商后缀或自助服务接口不同，需要修改源码中的校区参数。

七、安全与日志

密码使用 Windows DPAPI 加密，只保存在当前 Windows 用户目录。程序不会把账号密码写进日志。卸载请使用开始菜单或 Windows“应用和功能”。
